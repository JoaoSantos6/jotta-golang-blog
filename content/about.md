Olá! Sou o João, e este é meu blog de estudos em Go.

Comecei a aprender a linguagem recentemente e decidi criar este espaço para
registrar anotações, exercícios, pequenos projetos e — principalmente — os
erros que encontro pelo caminho. A ideia é simples: escrever sobre o que
aprendo em Go enquanto ainda estou aprendendo, tanto para consolidar o
conhecimento quanto para servir de referência (e talvez ajudar quem está
começando também).

Se você é dev iniciante em Go, recrutador ou só encontrou este blog por
acaso, seja bem-vindo.
